# Security policy

This repository is the starter template for [Glyph](https://github.com/glyphmusic/apps)
themes and extensions.

## Reporting a vulnerability

If you find a security issue in this template's validation workflow, in the
manifest validator (`glyphmusic/plugins`), or in Glyph's plugin sandbox, report
it privately through GitHub Security Advisories:

- **Template (`glyphmusic/plugin-template`):** [Report an advisory](https://github.com/glyphmusic/plugin-template/security/advisories/new)
- **Plugin catalog and validator (`glyphmusic/plugins`):** [Report an advisory](https://github.com/glyphmusic/plugins/security/advisories/new)
- **Desktop and Android app (`glyphmusic/apps`):** [Report an advisory](https://github.com/glyphmusic/apps/security/advisories/new)

Do **not** open a public issue or pull request for a security vulnerability.
See [Trust and safety](https://docs.glyph.my/plugins/security) for how Glyph
validates and sandboxes plugins.
